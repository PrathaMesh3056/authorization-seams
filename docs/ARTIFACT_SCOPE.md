# Artifact scope

## Included

| Area | What is included | Why |
|---|---|---|
| Manuscript | Corrected Markdown source, canonical 32-page PDF, vector figures, table hashes | The artifact under review |
| LaTeX export | Single-file `main.tex` and reference PDF | Standalone rebuild without Pandoc |
| Paper build | Hash-checking preprocess, table-width pass, code-span pass, preamble, build scripts | Reproduces the draft from source |
| Pilot 1 | Cases, design notes, adapters, locks, stored results, traces | APC → TraceGrant evidence |
| Pilot 3 | Cases, design notes, adapters, locks, stored results, traces, pinned prototype excerpt | APC → SentinelAgent evidence |
| Boundary run | Design notes, adapters, lock, stored results | V1/V2 bad-bridge variants |
| E1 extension | Cases, lock, reports, stored results | Action-narrowing family and resolving tests |
| Discriminating tests | Test design, mini-lock, stored results | Resolving evidence for Pilot 1 |
| Task D | Independent implementation, examples, tests, unit results, provenance inventory | Reproduces the TraceGrant-side gate independently |
| QA | Manifest, verifier, repository tests, copied internal QA/status records | Traceability of the frozen state |

## Excluded

| Area | Why it is not here |
|---|---|
| APC and Progent upstream checkouts | Third-party code; fetched at pinned commits by `scripts/bootstrap_vendor.py` |
| TraceGrant paper PDF and extracted text | Third-party paper; not redistributed |
| SentinelAgent full repository and audit tree | Large; only the pinned MIT excerpt needed by the second pilot is included |
| Virtual environments, caches, model files | Machine-local; recorded in the lock/provenance files instead |
| Frozen predecessor `MANUSCRIPT.md` and `CONSOLIDATED_CLAIMS.md` | Superseded wording; kept in the internal archive, not distributed |
| Generated paper build output | Regenerated by the build; canonical PDF is tracked |
| Poppler / PDF QA binaries | Local QA tooling only; not bundled or required |

## Third-party notices

- `tests/sentinelagent_audit_20261014/upstream/` contains a small excerpt from
  <https://github.com/ksrpatil/sentinelagent> at commit
  `b7b1add07b7485e99aa3b91882a3f8f879f2e357`. The upstream MIT license is
  included as `LICENSE`.
- APC, Progent, and TraceGrant are referenced by URL and commit/version. Their
  claims are not treated as verified inputs to this study.
- Progent is related work only. No Progent figure is reproduced, re-measured,
  or compared.

## Privacy and machine-local data

Some frozen manifests and audit logs record the machine paths used at run time.
The source tree keeps them byte-identical for hash verification. Before any
public release, run `scripts/sanitize_release.py` and publish the reviewed
`dist/sanitized/` tree; see `RELEASE_SANITIZATION.md`.
